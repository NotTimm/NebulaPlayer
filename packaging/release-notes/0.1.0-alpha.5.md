The fifth test build of **Nebula Player**: smoother on slower computers,
pages that fill the window, and updates from inside the app.

**This is still an alpha.** Please report what breaks.

## New

- **Updates from inside the app.** Nebula Player checks for a new version
  when it starts and shows a banner when there is one. On Windows (the
  installer or the zip) and on a Mac, click **Update now**, then
  **Restart now**: the download is checked against the project's
  signature before anything is replaced. Other installs say how to get
  the new version. The Fedora package from COPR doesn't check: `sudo dnf
  upgrade` brings new versions. You can turn the check off, or check
  now, in Settings → About, which also shows the version and how it was
  installed.

  This release is the first that can update itself, so the first update
  you'll see happen inside the app is the one after it.

## Fixed

- **Stutter while scrolling on slower computers.** The app redrew the
  whole page from scratch on every frame of a scroll; now it does that
  only when it needs to, and scrolling stays smooth on laptops.
- **The thin dark bars** down the left and right of every page and
  around the video are gone: pages and the player reach the window's
  edges.

## Changed

- **Play in mpv's own window** moved to a new **Experimental** section at
  the bottom of Settings. Videos play inside the app unless you turn it
  on.

## Installing

- **Fedora:** `sudo dnf copr enable timbo-slice/nebula-player`, then
  `sudo dnf install nebula-player` (or `sudo dnf upgrade`), or install
  the `.rpm` from here.
- **Ubuntu / Debian:** `sudo apt install ./nebula-player_*.deb`.
- **Any Linux:** the `.flatpak` or the `.AppImage`.
- **Windows:** run the `-setup.exe` (no admin rights needed), or unzip the
  `.zip` and run `nebula-player.exe`. Keep `libmpv-2.dll` and the
  `vulkan` folder next to it.
- **macOS (Apple Silicon):** open the `.dmg` and drag Nebula Player to
  Applications; the first time, right-click it and choose Open.

## Known limits

- SyncPlay has been tried between two copies of Nebula Player only, not
  yet with Jellyfin's own apps in the same group.
- In mpv's own window (and on macOS, which always uses it), pausing
  there pauses the group, but seeking there only moves you.
- Files play as they are, never transcoded.
