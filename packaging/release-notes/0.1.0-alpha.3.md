The third test build of **Nebula Player**. It adds **SyncPlay**, so you
can watch together with other Jellyfin apps, and fixes the window on
Windows.

**This is still an alpha.** Please report what breaks.

## New

- **SyncPlay (watch together)**, the way Jellyfin's web and desktop apps
  do it, so you can share a group with people using jellyfin-web,
  Jellyfin Media Player or the phone apps:
  - The new **people button** in the header (and in the player's top
    bar) opens SyncPlay: join a group from the list, or start a new one.
  - In a group, playing anything plays it for everyone. Pause, seeking,
    Skip Intro, and next and previous episode all happen for the whole
    group at the same moment.
  - Everyone's video loads first and the group starts together. If
    someone's connection stalls, the group waits for them.
  - Playing an episode queues the rest of the show, so the group moves
    on to the next episode together.
  - Someone joining partway through jumps straight to where the group
    is.
  - Messages tell you who joined or left the group.
  - From the group's menu you can stop playing along for a while ("Stop
    local playback") and come back ("Resume local playback"), or leave
    the group.
  - **Sync correction** (off by default, as in Jellyfin's apps) gently
    speeds up or skips to keep you exactly with the group. Turn it on in
    the group's menu if you drift apart. Speed changes are ignored in a
    group.

  Your server must allow SyncPlay for your user (Dashboard → Users →
  SyncPlay access).

## Fixed

- **Windows:** the window had two title bars' worth of buttons (Windows'
  own, and a second minimize/maximize/close under them). There's now just
  Windows' title bar, and it shows the app's icon. On Windows 11 the title
  bar also takes the app's own dark colours, so it blends into the app
  (Windows 10 makes it dark). KDE Plasma and macOS also use their own
  title bar now.
- **Windows:** this build may fix the page flickering while you scroll
  (it no longer opens a see-through window). If it still flickers,
  please say so.

## Installing

- **Fedora:** `sudo dnf copr enable timbo-slice/nebula-player`, then
  `sudo dnf install nebula-player` (or `sudo dnf upgrade`), or install
  the `.rpm` from here.
- **Ubuntu / Debian:** `sudo apt install ./nebula-player_*.deb`.
- **Any Linux:** the `.flatpak` or the `.AppImage`.
- **Windows:** run the `-setup.exe` (no admin rights needed), or unzip the
  `.zip` and run `nebula-player.exe`. Keep `libmpv-2.dll` and the
  `vulkan` folder next to it.
- **macOS (Apple Silicon):** open the `.dmg` and drag Nebula Player to
  Applications; the first time, right-click it and choose Open.

## Known limits

- SyncPlay has been tried between two copies of Nebula Player only, not
  yet with Jellyfin's own apps in the same group.
- In mpv's own window (and on macOS, which always uses it), pausing
  there pauses the group, but seeking there only moves you.
- Files play as they are, never transcoded.
