The sixth test build of **Nebula Player**: smoother menus on slower
computers, and a cleaner featured banner.

**This is still an alpha.** Please report what breaks.

## Faster

- **Scrolling through libraries and the home screen is much lighter.**
  Posters and other pictures were downloaded bigger than they're shown,
  and every one coming into view was shrunk again on the computer's
  processor, right while you scrolled. Now each picture is downloaded
  at the size it's shown (sharp on HiDPI screens too), so there's
  nothing to shrink. Pictures also download faster and use less memory.
- **Fewer redraws while pictures load.** Pictures that arrive together
  now update the page once, not once each.

## New

- **The featured banner fades** out and back in when it moves to the
  next item, whether on its own, with the arrows or with the dots.

## Changed

- Updated the libraries the app is built on (networking, SyncPlay's
  connection, the updater's zip reader, and the build tools).

## Installing

- **Already on 0.1.0-alpha.5 on Windows or a Mac:** the app offers this
  update itself: click **Update now**, then **Restart now**.
- **Fedora:** `sudo dnf copr enable timbo-slice/nebula-player`, then
  `sudo dnf install nebula-player` (or `sudo dnf upgrade`), or install
  the `.rpm` from here.
- **Ubuntu / Debian:** `sudo apt install ./nebula-player_*.deb`.
- **Any Linux:** the `.flatpak` or the `.AppImage`.
- **Windows:** run the `-setup.exe` (no admin rights needed), or unzip the
  `.zip` and run `nebula-player.exe`. Keep `libmpv-2.dll` and the
  `vulkan` folder next to it.
- **macOS (Apple Silicon):** open the `.dmg` and drag Nebula Player to
  Applications; the first time, right-click it and choose Open.

## Known limits

- SyncPlay has been tried between two copies of Nebula Player only, not
  yet with Jellyfin's own apps in the same group.
- In mpv's own window (and on macOS, which always uses it), pausing
  there pauses the group, but seeking there only moves you.
- Files play as they are, never transcoded.
